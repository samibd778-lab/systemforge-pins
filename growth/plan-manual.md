# SystemForge: what Sami does by hand (offer + 30–60 min a day)

## A. Gumroad changes (once, ~20 min)

1. **Proposal Tracker → pay what you want**
   - Edit product → Price: `0+`, suggested price `$12`.
   - Goal: get first downloads, emails and ratings. Inside the template there is already a link to Freelancer Client OS.
2. **Prices** (Edit product → Price)
   - Freelancer Client OS: `$19`
   - Content Creator Studio: `$19`
   - Brand Deal Tracker: `$14`
   - Freelance Invoice Tracker (if it is on Gumroad): `$12`
3. **Launch discount (14 days)**: Checkout → Discounts → New discount
   - Name: `LAUNCH30`, 30% off, all products, ends Nov 11.
   - Add one line at the top of each description: `Launch week: 30% off with code LAUNCH30 (until Nov 11).`
4. **Black Friday**: same thing, code `BF40`, 40% off, Nov 27–30.
5. **Bundles** (New product → Bundle):
   - **Freelancer Bundle**: Freelancer Client OS + Proposal Tracker + Freelance Invoice Tracker, `$29`.
   - **Creator Bundle**: Content Creator Studio + Brand Deal Tracker, `$29`.
6. **Every product page**: put one of the new reels (videos/*.mp4) as the first item of the cover gallery. Video converts better than a still image.
7. **Ask for ratings**: after each free download or sale, send a short thank-you email from Gumroad (Emails → New email) asking for a rating.
